하루 10분 30일 생활영어 v8 — 수동 학습 완료 및 메모 UI 개선

- 화면 오른쪽 하단의 메모 버튼 제거. 문장 옆 ✎ 아이콘을 눌러 메모 창을 엽니다.
- 메모창의 상단/하단 닫기 버튼 모두 제거. 메모 저장을 누르면 저장 후 닫힙니다.
- 학습 완료 체크는 메모창의 ✓ 학습 완료 버튼을 직접 클릭할 때만 변경됩니다.
- 영상 자동 진행, 반복, 다음 문장, 영상 종료는 학습 완료를 변경하지 않습니다.
- 이전 버전은 재생 시 자동으로 학습 완료를 표시했으므로, 과거 완료 기록은 자동/수동을 구별할 수 없습니다. v8은 구분을 위해 새로운 수동 전용 완료 기록(manualDone)을 사용합니다. 이전 기록(done)은 삭제하지 않습니다.
- 기존 즐겨찾기·메모·학습 위치 및 기기에 보관한 영상은 그대로 유지합니다.
- 메모를 저장하지 않고 닫으려면 Esc (키보드) 사용.
- GitHub 업로드: ZIP 해제 -> 저장소 루트에 전체 업로드 -> Commit changes. 기존 앱의 사이트 데이터 삭제 금지.
